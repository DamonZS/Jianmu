Raycast on any model

Raycast AI takes models of your own as custom providers (Raycast Pro, on Mac and Windows). jianmu adds itself to Raycast as one, so Quick AI, AI Chat and AI Commands can run on any model you have in jianmu: DeepSeek, Kimi, GLM, Qwen, an OpenAI key, or a ChatGPT or Copilot subscription, with no key pasted into Raycast.

Raycast reads its custom providers from ~/.config/raycast/ai/providers.yaml in your user folder, on Mac and on Windows. jianmu adds one entry to its providers list, with the id jianmu: the gateway’s OpenAI-compatible address, a key of Raycast’s own and jianmu’s models. Raycast watches the file, so the models show up without a restart. The gateway translates each request for the model’s provider, tool calls and reasoning included.

Connect Raycast

  1. Add providers in jianmuIn the Providers tab, add an API key or sign in to a subscription.
  2. Put jianmu on Raycast’s rowIn the Agents tab, set Raycast’s provider to jianmu.
  3. Pick a model in RaycastOpen Raycast’s model picker in Quick AI, AI Chat or an AI Command. jianmu’s models are listed under jianmu.
Terminal
jianmu raycast jianmu     # jianmu's models in Raycast AI's picker
jianmu raycast            # what Raycast is set to now

On Windows, Raycast makes its config folder when you open Reveal Providers Config in its settings; jianmu finds Raycast by that folder there.

Which models it lists

The model is picked in Raycast, not in a file, so Raycast’s picker lists the models picked for Raycast on the Agents page. Hide one there and it leaves Raycast’s list. Each model comes with its name, context window and abilities, all spelled out, because Raycast assumes tools and vision off when they aren’t:

  • Tools on for every model, so AI Extensions work.
  • Vision on for a model that takes images.
  • Reasoning effort on for a model with effort levels.
  • Temperature off for a model that refuses it.

Your providers.yaml

jianmu writes only its own entry. Your other providers, the top-level tools block and your comments stay. So do keys you add to jianmu’s entry yourself, such as include_user_email, additional_parameters or a model’s description. The file is written only when jianmu’s entry would change.

Switch back

Take Raycast’s row off jianmu, or run jianmu raycast default. jianmu removes its entry, the providers list too if it was the only one, and the file if nothing else is left in it.

FAQ

Do I need Raycast Pro?

Yes. Custom providers are a Raycast Pro feature, so jianmu’s models show in Raycast’s picker on a Pro plan.

Can Raycast use my ChatGPT subscription?

Yes. Sign in to ChatGPT in jianmu and put jianmu on Raycast’s row, then pick a GPT model in Raycast. Raycast sends its requests to jianmu, which uses the subscription.

Do I need to restart Raycast?

No. Raycast watches providers.yaml and picks up jianmu’s entry when it changes.

Do AI Extensions work?

Yes. Every model is listed with tools on, and the gateway carries tool calls to each model’s provider.
