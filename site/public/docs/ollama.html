Ollama in Claude Code, Codex, Gemini CLI and OpenCode

Ollama serves the models you pull on two APIs, OpenAI Chat Completions and Anthropic Messages, at http://localhost:11434. Ollama Cloud serves its models the same way at ollama.com, with an API key. Add either to jianmu once, and Claude Code, Codex, Gemini CLI, OpenCode and every other agent you connect can use them through jianmu’s local gateway at 127.0.0.1:3425, each agent with a model of its own.

Add Ollama

  1. Pull a modelPull a model in Ollama, such as qwen3, and leave the server running.
  2. Add the providerIn jianmu’s Providers tab, press ＋ Add provider and pick Ollama under On this machine. No key is needed. jianmu asks the server which models it has, and they show as ollama/….
  3. Pick it for an agentIn the Agents tab, click the model on the agent’s row and choose an Ollama model.
Terminal
ollama pull qwen3
jianmu provider add ollama
jianmu provider test ollama

Model ids in jianmu are provider/model, so a model you pulled as qwen3 reads ollama/qwen3. A tag stays in the id, as in ollama/qwen3:8b. In the terminal UI, jianmu asks for the server’s address when you add it. LM Studio, oMLX, vLLM and llama.cpp’s server are in Local models.

Another port or another computer

If Ollama listens on another port, or runs on another computer such as a GPU box or a NAS, change Server address in the provider’s editor. Only the scheme, host and port change; each API keeps its path. The scheme can be left out, and http is taken; a path pasted with the address, such as /v1, is dropped.

Terminal
jianmu provider set ollama address=192.168.1.20:11434
jianmu provider set ollama address=     # back to the default
  • Proxies. A server on your own network is reached directly, whatever proxy Settings or the system name. A proxy you set on the provider itself is still used.
  • HTTPS. An Ollama behind HTTPS with a self-signed certificate can be reached with Don't check its certificate in the editor. It applies to that provider’s own hosts only.

Ollama Cloud

  1. Get a keyMake one at ollama.com/settings/keys.
  2. Add the providerIn the Providers tab, press ＋ Add provider, pick Ollama Cloud, paste the key and save. jianmu asks Ollama Cloud which models the key can use.
  3. Pick it for an agentChoose an Ollama Cloud model, such as deepseek-v4-pro, on the agent’s row.
Terminal
jianmu provider add ollama-cloud <key>
jianmu claude ollama-cloud/deepseek-v4-pro

Names, reasoning levels and prices come from models.dev’s ollama-cloud catalog. The key is kept in jianmu’s settings.

An agent whose API Ollama serves is passed on to that API. jianmu uses no Responses endpoint for either, so when it has to translate, it uses Chat Completions: it keeps Responses first only for OpenAI’s own models, and Messages first only for Claude models.

Model list

jianmu asks the server for its list at the Chat Completions base: http://localhost:11434/v1/models, or https://ollama.com/v1/models for Ollama Cloud. A model shows in jianmu once Ollama has it. After you pull another, press Fetch models in the provider’s editor, or run jianmu provider refresh ollama. Pick the models agents see in the provider’s model list, or from the terminal:

Terminal
jianmu provider refresh ollama
jianmu provider models ollama +qwen3

Ollama 0.35.0 and later (0.40.5 for its cloud models) also serves decision models, such as Nimble, Clef and Tev. jianmu reads Ollama’s /api/tags as well, and a model marked there as a decision model becomes one of the provider’s decision models for intent routing, never an agent’s model. An older Ollama lists none.

In each agent

Terminal
jianmu claude ollama/qwen3
jianmu codex ollama/qwen3
jianmu gemini model ollama/qwen3
jianmu opencode ollama/qwen3
  • Claude Code speaks Anthropic Messages, and so does Ollama at http://localhost:11434, so its requests go there as they are. Models in Claude Code.
  • Codex speaks OpenAI Responses, which jianmu doesn’t send to Ollama. jianmu turns each request into Chat Completions and the reply back, streaming and tool calls included. Models in Codex.
  • Gemini CLI speaks Google’s Gemini API. jianmu translates each request to Chat Completions and the reply back. Models in Gemini CLI.
  • OpenCode speaks Chat Completions, so its requests go to Ollama’s /v1 as they are. Models in OpenCode.

Inside the agent, Claude Code’s and Codex’s /model list jianmu’s models too, so you can move between a local model and a cloud one there. To go back to the agent’s own models, run jianmu claude default or jianmu codex default.

Context window and num_ctx

Agents plan around how long a request the model takes. Claude Code takes a model it doesn’t know for 200K, and Codex compacts a conversation at 90% of the window it is told. jianmu doesn’t read an Ollama chat model’s window, so tell it the real one: Context window under Advanced in the provider’s editor, for every model or one of them. jianmu passes it on to the agents.

Terminal
jianmu provider set ollama context=32k
jianmu provider set ollama context.qwen3=128k
  • num_ctx. Some clients send Ollama’s per-request options, such as {"num_ctx": …}, beside the Chat Completions fields. jianmu leaves them out of every request it sends on: no Chat Completions API reads them, Ollama’s own /v1 included. The window the model runs with is Ollama’s to set; give jianmu the same number.
  • Too long. When a conversation outgrows the window, Ollama answers “exceeded max context length”. jianmu tells the agent so the way it understands, context_length_exceeded or Anthropic’s “prompt is too long”, so the agent compacts and tries again.

Reasoning

  • Effort. The effort an agent asks for is fitted to the nearest level the model has, as the catalog lists them. A model whose levels jianmu doesn’t know is asked as the agent asked.
  • Reasoning off. When an agent whose requests jianmu translates, such as Codex or Gemini CLI, turns reasoning off and the model lists none among its levels, jianmu asks for none.
  • Your own levels. jianmu model efforts offers only the levels you name, or sends a model no reasoning field at all.
Terminal
jianmu model efforts ollama/qwen3 low,medium,high
jianmu model efforts ollama/qwen3 off

Tool calls

Claude Code’s and OpenCode’s tool calls reach Ollama as the agent wrote them. For Codex and Gemini CLI, jianmu translates the tools, the model’s calls and their results to Chat Completions and back, in streamed replies too.

Privacy masking

jianmu’s privacy masking replaces keys, tokens and other secrets with placeholders before a request leaves the gateway, a request to a local Ollama too. When the model runs on your own computer or network, you can turn on Send requests unmasked in its editor, or run jianmu provider set ollama unmasked=yes.

  • Cloud models. Ollama’s cloud models pass a request on to a vendor whatever the address, so it is your call. The editor warns you while it is on for a provider that isn’t local, such as Ollama Cloud.
  • Tool arguments. In a request in Ollama’s own format, a tool call’s arguments are masked as tool arguments, as in every other API.
  • Anonymous stats. jianmu’s daily stats name an Ollama model only when models.dev knows it; any other counts as “other”. See Privacy.

Usage and cost

  • Usage. The Usage tab counts the tokens of every Ollama call. A model is priced at the price jianmu finds for its id, which for a local model can be its maker’s list price. To count a local model at nothing, give it your own price.
  • Free first. free=yes counts every model of the provider as free, so a Free first routing spends it before paid ones. Prices and Usage’s costs stay as listed.
  • Ollama Cloud’s allowance. jianmu reads the account’s balance from Ollama Cloud. The included allowance shows as a plan, in dollars used, with when it resets; an older plan shows its session and weekly limits instead. Credits you bought show as a balance. Past the allowance Ollama Cloud draws on those credits, so a spent allowance with credits left doesn’t stop the key.
  • Peak hours. On Ollama Cloud, deepseek-v4.1-flash and deepseek-v4-pro (with their tags) cost double from 12:00 to 18:00 UTC, Monday to Friday. models.dev lists the off-peak price; the Usage tab doubles it in those hours, and a Cheapest first routing counts it.
  • Out of allowance. When Ollama Cloud says a key is out without saying when it comes back, as its weekly limit does, jianmu rests the key for 15 minutes. quota-rest sets how long, up to 8 days. With several keys (Add another key) the next one takes over; when every key is out, the gateway answers at once with Retry-After.
Terminal
jianmu model price ollama/qwen3 0,0,0,0
jianmu provider set ollama free=yes
jianmu provider quota-rest ollama-cloud 7d
jianmu provider fallback ollama-cloud ollama/qwen3

jianmu as an Ollama server

Some apps take a custom model only as an Ollama server: VS Code’s Copilot Ollama provider, Visual Studio’s Copilot BYOK, Zed’s Ollama provider and the ollama CLI. Point them at jianmu’s gateway, http://127.0.0.1:3425, and they see jianmu’s models, from every provider, not only Ollama.

  • Routes. jianmu answers /api/version, /api/tags, /api/show, /api/chat and /api/generate.
  • The same path. A chat there is served as /v1/chat/completions is, so key limits, routing, fallbacks and usage are the same. A gateway key held to some models lists only those.
  • What it tells. /api/tags and /api/show mark tools, vision when the model reads images, and thinking when it reasons. /api/show also gives the model’s window, or 32768 for one jianmu doesn’t know. The ollama CLI’s name:latest finds a model called name.

Troubleshooting

  • A model you pulled isn’t listed. The list comes from the server. Press Fetch models, or run jianmu provider refresh ollama, and pick it in the provider’s model list. Use the name Ollama lists, tag included.
  • Ollama isn’t running. jianmu provider test ollama sends a tiny request through each endpoint, or to each model you name; add --as codex or --as claude-code to send it the way that agent would. Start Ollama, or check Server address. fallback names where requests go while it is down.
  • “exceeded max context length”. The conversation is longer than the model was loaded for. Set the real Context window on the provider, and the agents compact before they reach it.
  • Another computer can’t be reached. Check the address and port in Server address; for HTTPS with a self-signed certificate, turn on Don't check its certificate.

FAQ

How do I use Ollama in Claude Code?

Add Ollama in jianmu (Providers, Add provider, Ollama under On this machine), then pick one of its models on Claude Code’s row, or run jianmu claude ollama/qwen3. Claude Code’s requests go through jianmu’s gateway to Ollama’s Anthropic Messages API at http://localhost:11434 as they are.

Can Codex use Ollama?

Yes. Codex speaks only the Responses API, so jianmu turns its requests into Chat Completions for Ollama, and the replies back, tool calls included. Run jianmu codex ollama/qwen3.

Can Gemini CLI and OpenCode use Ollama?

Yes. Gemini CLI speaks Google’s API, so jianmu translates its requests to Ollama’s Chat Completions and the replies back. OpenCode speaks Chat Completions, so its requests go to Ollama as they are. Run jianmu gemini model ollama/qwen3 or jianmu opencode ollama/qwen3.

How do I run qwen3-coder from Ollama in Claude Code?

Pull it in Ollama, press Fetch models in the provider’s editor in jianmu (or run jianmu provider refresh ollama), and pick it on Claude Code’s row. Its id in jianmu is ollama/ and the name Ollama lists it under, tag included. Set its Context window too: Claude Code takes a model it doesn’t know for 200K.

Can jianmu use Ollama on another computer?

Yes. Set the provider’s Server address to that computer, such as jianmu provider set ollama address=192.168.1.20:11434. A server on your own network is reached directly, not through a proxy set in Settings or the system.

Does jianmu work with Ollama Cloud?

Yes. Add Ollama Cloud with a key from ollama.com/settings/keys. jianmu lists the models the key can use, prices them from models.dev, and shows the account’s included allowance and the credits you bought.

Do I need an API key for a local Ollama?

No. The Ollama preset takes none. Ollama Cloud needs one.

Other local servers, such as LM Studio, oMLX, vLLM and llama.cpp’s server, are in Local models. To let a local model classify each request for routing, see Intent routing.
