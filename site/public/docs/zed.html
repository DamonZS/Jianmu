Zed on any model

Zed’s agent panel runs on the language model provider in its settings. jianmu adds itself to Zed as an OpenAI-compatible provider, so Zed’s agent can run on any model you have in jianmu: DeepSeek, Kimi, GLM, Qwen, an OpenAI key, or a ChatGPT or Copilot subscription, with no key pasted into Zed.

Zed keeps its settings in ~/.config/zed/settings.json on macOS and Linux (under $XDG_CONFIG_HOME if set) and in %APPDATA%\Zed on Windows. jianmu adds language_models.openai_compatible.jianmu, with the gateway’s address and jianmu’s models, and sets agent.default_model to the model you pick. Zed reads the change as it runs. The gateway translates each request for the model’s provider, tool calls and reasoning included.

Connect Zed

  1. Add providers in jianmuIn the Providers tab, add an API key or sign in to a subscription.
  2. Pick a model on Zed’s rowIn the Agents tab, choose a model on Zed’s row.
  3. Open Zed’s agent panelThe model is the panel’s default, and jianmu’s models are in its model picker under jianmu.
Terminal
jianmu zed deepseek/deepseek-v4-pro    # Zed's agent on DeepSeek
jianmu zed                             # what Zed runs on now

The API key

Zed keeps an OpenAI-compatible provider’s key in the system’s credential store, keyed by the provider’s address, not in settings.json. jianmu saves a key of Zed’s own there for you: in the Keychain on macOS, in the Secret Service on Linux and in the Credential Manager on Windows. If Zed still asks for an API key, restart Zed.

Models and thinking

Each model carries its context window and reply limit, so Zed knows when to compact, and whether it takes images. A model that thinks is written with reasoning_effort high, or the strongest level it has, so Zed shows its thinking switch and levels. A level you set on a model in settings.json yourself, none included, stays when jianmu rewrites the list. If Zed reaches the gateway through a proxy of yours, jianmu keeps that address.

Switch back

Pick one of Zed’s own models on its row, take the row off jianmu, or run jianmu zed default. jianmu puts back the default model, and the provider entry, you had before.

FAQ

Can Zed use my ChatGPT subscription?

Yes. Sign in to ChatGPT in jianmu and pick a GPT model on Zed’s row. Zed sends its requests to jianmu, which uses the subscription.

Zed asks for an API key for jianmu.

jianmu saved the key in the system credential store. Restart Zed so it reads it.

Why doesn’t Zed show a thinking switch for a model?

That model doesn’t think. For one that does, jianmu sets reasoning_effort, and Zed then shows the switch.

Does this change Zed’s edit predictions?

No. jianmu sets the agent panel’s default model and adds a provider; edit predictions are left as they were.
