Droid on any model

Droid, Factory’s coding agent, can run on custom models of your own. jianmu adds the models you have in jianmu to Droid as custom models, so droid can run on DeepSeek, Kimi, GLM, Qwen, an OpenAI key, or a ChatGPT or Copilot subscription, with no key pasted into Droid.

Droid keeps its settings in ~/.factory/settings.json (under $FACTORY_HOME_OVERRIDE when set). jianmu adds one entry to its customModels per model in jianmu, with the gateway’s address and a key of Droid’s own, and sets sessionDefaultSettings.model, the model sessions start on. Each model goes on the API its provider speaks, Anthropic Messages, OpenAI Responses or Chat Completions, so the gateway relays it as it is. A droid in WSL is set up the same way, reaching the gateway as the distro sees it.

Connect Droid

  1. Add providers in jianmuIn the Providers tab, add an API key or sign in to a subscription.
  2. Pick a model on Droid’s rowIn the Agents tab, choose a model on Droid’s row.
  3. Restart droidDroid reads its settings as it starts: open sessions keep what they have, so start droid again.
Terminal
jianmu droid deepseek/deepseek-v4-pro    # Droid on DeepSeek
jianmu droid                             # what Droid runs on now

Models and thinking levels

jianmu’s models are in droid’s /model picker too, under Custom models, so you can switch inside a session. A model that reasons is given a starting effort, so the picker offers its levels (off, low, medium and high); one that is a model Droid has built in takes Droid’s own levels and default. A model whose name Droid reads as OpenAI’s or Claude’s is written on the API Droid expects for it, so Droid doesn’t warn at each session start.

Your own models

Custom models you added yourself stay as they were, ahead of jianmu’s, so their ids don’t move. If you change a field of one of jianmu’s entries in settings.json, such as its name or effort, jianmu keeps your value; only the address and key are put back at each sync. The older ~/.factory/config.json is left alone.

Switch back

Take Droid’s row off jianmu, or run jianmu droid default. jianmu removes its custom models and puts back the default model you had.

FAQ

Can Droid use my ChatGPT subscription?

Yes. Sign in to ChatGPT in jianmu and pick a GPT model on Droid’s row. droid sends its requests to jianmu, which uses the subscription.

I changed the model but droid still uses the old one.

Droid reads its settings as it starts. Restart droid, or switch with /model inside the session.

Why does /model show no thinking levels for a model?

That model doesn’t reason. For one that does, jianmu gives it a starting effort, and droid then offers its levels.

Will jianmu touch my own BYOK models?

No. Your custom models stay as they were and in front of jianmu’s.
