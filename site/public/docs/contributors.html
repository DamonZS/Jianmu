Contributors

jianmu is shaped by the people who tell us what broke and ask for what is missing. Everyone below is credited in jianmu’s history, with the releases their reports, ideas or code went into, newest first. Thank you.

The list

The list is built from git history when the site is deployed, and isn’t here right now. Each release’s notes on GitHub end with the people it thanks.

How names are found

A name is listed when one of these is true of a commit that went out in a release:

  • its subject credits the person, as in (name on Discord) or (spotted by @login);
  • it names an issue or pull request (#1234, plugins#56) the person opened on GitHub;
  • the person wrote it, or is a co-author on it.

Only names already public in jianmu’s history are used, as they are written there; no email address is shown. The maintainer, coding agents and bots aren’t listed. A name that links to GitHub is that account; a platform under a name is where the report came from. The list is brought up to date each time the site is deployed, and each release’s notes thank its own people the same way.

To be left off

If you don’t want your name here or in release notes, say so on open an issue, or send a pull request adding it to site/contributors-exclude.txt. It is left out from the next deploy and the next release. The same goes for a name that is wrong or missing.
