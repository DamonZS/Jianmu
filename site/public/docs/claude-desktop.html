Claude Desktop on any model

Claude Desktop has a third-party gateway mode: no Anthropic sign-in, and its Code and Cowork tabs work on any plan. jianmu sets Desktop up in that mode with jianmu’s gateway, so Desktop runs on any model you have in jianmu: DeepSeek, Kimi, GLM, Qwen, an OpenAI key, or a ChatGPT or Copilot subscription.

In its gateway mode Claude Desktop sends every request to one address instead of Anthropic. jianmu writes that mode and a profile named jianmu, pointing at its gateway, http://127.0.0.1:3425, into Desktop’s configuration folders. The gateway speaks Anthropic’s Messages API and translates each request for the model you picked, streaming, tool calls and reasoning included. It works on macOS, Windows (the Store package too) and Linux.

Turn it on

  1. Add providers in jianmuIn the Providers tab, add an API key or sign in to a subscription.
  2. Choose jianmu on Claude Desktop’s rowIn the Agents tab, Claude Desktop’s row offers jianmu: Desktop’s third-party gateway, Code and Cowork on jianmu’s models, no Anthropic sign-in.
  3. Quit and reopen Claude DesktopDesktop reads this only as it starts.
Terminal
jianmu claude-desktop jianmu      # Desktop on jianmu's gateway
jianmu claude-desktop default     # back to the Anthropic sign-in

Pick a model

Desktop lists the gateway’s models when it starts, so its model picker shows the models you have in jianmu. A model with a 1M context window is listed once, as its 1M entry. After you add a provider in jianmu, quit and reopen Desktop to see its models.

The Code tab’s tiers

The Code tab runs Claude Code, which asks for models by tier: opus, sonnet, haiku. Left unset, a tier runs on the chat’s model. Pick a model for a tier on Claude Desktop’s row, or from a terminal, and restart Desktop after a change:

Terminal
jianmu claude-desktop sonnet deepseek/deepseek-v4-pro
jianmu claude-desktop haiku deepseek/deepseek-v4-flash

A picked model runs with the prompt of the Claude model of its tier. The row also has a subagent model, which takes effect without a restart.

Your chats and projects

Desktop keeps its gateway mode in a profile of its own, so chats and projects from your Anthropic sign-in don’t show while it runs on jianmu. Nothing is deleted, and switching back brings them back. To go on with them on jianmu, use Settings → Import in Desktop, which copies in your Claude.ai chats and projects and leaves the originals as they are.

A separate Claude Jianmu app (Mac)

On a Mac, jianmu can run Desktop’s gateway mode in a folder of its own, started by ~/Applications/Claude Jianmu.app. Your own Claude Desktop stays signed in with Anthropic, and both run side by side. It is off by default.

Terminal
jianmu claude-desktop launcher add      # make Claude Jianmu.app
jianmu claude-desktop launcher remove

Switch back

Take Claude Desktop’s row off jianmu, or run jianmu claude-desktop default, then quit and reopen Desktop. jianmu puts Desktop’s files back as they were, and your chats from before are there again.

FAQ

Do I need a Claude subscription for Cowork and the Code tab?

No. In gateway mode, Desktop’s Code and Cowork tabs work without an Anthropic sign-in, on whatever model jianmu serves.

Can I use my ChatGPT subscription in Claude Desktop?

Yes. Sign in to ChatGPT in jianmu, and its GPT models appear in Desktop’s model picker after a restart.

Why doesn’t Claude Desktop show a new model?

Desktop reads the model list as it starts. Quit and reopen it.

Why is Claude Desktop in English on jianmu?

Desktop’s gateway-mode window has no translation of its own. Switching back brings your language back.

Are my old chats gone?

No. They stay in Desktop’s own profile and come back when you switch back, or you can import them with Settings → Import.
