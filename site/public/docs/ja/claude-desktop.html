Claude Desktop を任意のモデルで

Claude Desktop にはサードパーティゲートウェイのモードがあります。Anthropic へのサインインは不要で、Code と Cowork はどのプランでも使えます。jianmu は Desktop をこのモードにして jianmu のゲートウェイを向けるので、jianmu にあるどのモデルでも Desktop が動きます：DeepSeek、Kimi、GLM、Qwen、OpenAI キー、ChatGPT や Copilot のサブスクリプション。

ゲートウェイモードの Claude Desktop は、すべてのリクエストを Anthropic ではなく一つのアドレスに送ります。jianmu は Desktop の設定フォルダに、このモードと jianmu という名前のプロファイルを書き込み、ゲートウェイ http://127.0.0.1:3425 を向けます。ゲートウェイは Anthropic の Messages API を話し、各リクエストを選んだモデル向けに変換します。ストリーミング、ツール呼び出し、推論もそのままです。macOS、Windows（ストア版も）、Linux で動きます。

有効にする

  1. jianmu にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクリプションにサインインします。
  2. Claude Desktop の行で jianmu を選ぶエージェント タブの Claude Desktop の行で jianmu を選びます。Desktop のサードパーティゲートウェイで、Code と Cowork が jianmu のモデルで動き、Anthropic へのサインインは不要です。
  3. Claude Desktop を終了して開き直すDesktop はこれを起動時にしか読みません。
ターミナル
jianmu claude-desktop jianmu      # Desktop を jianmu のゲートウェイで
jianmu claude-desktop default     # Anthropic のサインインに戻す

モデルを選ぶ

Desktop は起動時にゲートウェイのモデル一覧を読むので、モデル選択には jianmu にあるモデルが並びます。1M のコンテキストを持つモデルは 1M のものだけが一つ出ます。jianmu にプロバイダを追加したら、Desktop を終了して開き直すとそのモデルが出ます。

Code タブの階層

Code タブは Claude Code を動かし、Claude Code は opus、sonnet、haiku の階層でモデルを求めます。設定しなければ、階層はチャットのモデルで動きます。Claude Desktop の行かターミナルで階層のモデルを選び、変更後は Desktop を再起動します：

ターミナル
jianmu claude-desktop sonnet deepseek/deepseek-v4-pro
jianmu claude-desktop haiku deepseek/deepseek-v4-flash

選んだモデルは、その階層の Claude モデルのプロンプトで動きます。行にはサブエージェントのモデルもあり、こちらは再起動なしで反映されます。

元のチャットとプロジェクト

Desktop はゲートウェイモードを別のプロファイルで動かすので、jianmu で動いている間は Anthropic のサインインでのチャットやプロジェクトは表示されません。何も削除されず、元に戻すと戻ってきます。jianmu で続けたい場合は、Desktop の Settings → Import で Claude.ai のチャットとプロジェクトをコピーできます。元のものはそのままです。

別アプリの Claude Jianmu（Mac）

Mac では、jianmu が Desktop のゲートウェイモードを専用のフォルダで動かし、~/Applications/Claude Jianmu.app から起動できます。自分の Claude Desktop は Anthropic にサインインしたままで、両方を並べて使えます。既定ではオフです。

ターミナル
jianmu claude-desktop launcher add      # Claude Jianmu.app を作る
jianmu claude-desktop launcher remove

元に戻す

Claude Desktop の行で jianmu を外すか、jianmu claude-desktop default を実行し、Desktop を終了して開き直します。jianmu は Desktop のファイルを元どおりに戻し、以前のチャットも戻ってきます。

よくある質問

Cowork と Code タブに Claude のサブスクは要りますか？

要りません。ゲートウェイモードでは、Desktop の Code と Cowork は Anthropic へのサインインなしで、jianmu が提供するモデルで動きます。

Claude Desktop で ChatGPT サブスクを使えますか？

使えます。jianmu で ChatGPT にサインインし、Desktop を再起動すると GPT モデルがモデル選択に出ます。

新しいモデルが Claude Desktop に出ないのはなぜですか？

Desktop はモデル一覧を起動時に読みます。終了して開き直してください。

jianmu で動かすと Claude Desktop が英語になるのはなぜですか？

Desktop のゲートウェイモードの画面には翻訳がありません。元に戻すと言語も戻ります。

以前のチャットは消えましたか？

消えていません。Desktop の元のプロファイルに残っていて、元に戻すと戻ります。Settings → Import で取り込むこともできます。

ターミナルで同じモデルを使うには Claude Code で他のモデルと Claude Code で ChatGPT サブスクを使うを参照してください。エラーが出るときは よくあるエラーの直し方、または GitHub Issues で質問してください。
