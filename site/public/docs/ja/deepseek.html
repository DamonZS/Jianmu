DeepSeek を Claude Code・Codex・Gemini CLI・OpenCode で使う

DeepSeek は OpenAI 互換と Anthropic 互換の両方の API を提供しています。jianmu にキーを一度追加すれば、Claude Code、Codex、Gemini CLI、OpenCode、ほかに接続したツールのすべてが、jianmu のゲートウェイ 127.0.0.1:3425 を通して DeepSeek のモデルを使えます。

DeepSeek を追加する

  1. API キーを取得platform.deepseek.com/api_keys で作成します。
  2. プロバイダを追加jianmu の プロバイダ タブで ＋ プロバイダを追加 を押し、DeepSeek を選んでキーを貼り付け、保存します。jianmu が DeepSeek に提供モデル（deepseek-v4-pro、deepseek-v4-flash など）を問い合わせます。
  3. ツールで選ぶエージェント タブで、ツールの行のモデルをクリックして DeepSeek のモデルを選びます。
ターミナル
jianmu provider add deepseek sk-…
jianmu models        # すべてのモデル（provider/model 形式）

jianmu のモデル ID は provider/model 形式で、DeepSeek のものは deepseek/… です。プリセットをもう一度追加すると、別のキー用に 2 つ目の DeepSeek プロバイダができます。複数のキーにリクエストを振り分けたいときは、1 つのプロバイダにまとめて追加します。

エンドポイント

DeepSeek のプランは従量課金だけで、jianmu が使うエンドポイントは次のとおりです。

APIベース URL
OpenAI Chat Completions と Responseshttps://api.deepseek.com/v1
Anthropic Messageshttps://api.deepseek.com/anthropic

ツールごとの使い方

エージェント タブで各ツールの行のモデルをクリックして選ぶか、ターミナルで選びます。各ガイドに、jianmu がそのツールの設定に何を書くか、どう元に戻すかがあります。

ターミナル
jianmu claude deepseek/deepseek-v4-pro
jianmu codex deepseek/deepseek-v4-pro
jianmu gemini model deepseek/deepseek-v4-flash
jianmu opencode deepseek/deepseek-v4-pro
  • Claude Code は Anthropic Messages を話し、DeepSeek の Anthropic エンドポイントも同じなので、リクエストはそのまま渡されます。opus・sonnet・haiku の各ティアは、個別に指定しない限り選んだモデルで動きます。Claude Code で他のモデル。
  • Codex が話すのは OpenAI Responses だけです。DeepSeek は Responses API を自分で提供しているので、Codex のリクエストはそのまま渡されます。モデルは推論レベル付きで Codex の /model に並びます。Codex で他のモデル。
  • Gemini CLI は Gemini の API を話します。jianmu がゲートウェイに向けて変換します。Gemini CLI で他のモデル。
  • OpenCode には、jianmu が opencode.json にモデルを推論バリアントと価格つきで書きます。OpenCode で他のモデル。

思考・推論レベル・キャッシュ

  • ツールのターンの思考ブロック。DeepSeek の Anthropic エンドポイントは、ツールを呼ぶアシスタントのターンと、ツールの結果だけを返すターンのすべてに思考ブロックを求めます。履歴にないときは jianmu が補い、Claude の redacted_thinking も使える思考ブロックに変えます。そのためルーティンググループは会話の途中で Claude から DeepSeek に切り替えられます。
  • 推論レベル。DeepSeek は low・high・max の 3 段階で考え、output_config.effort で指定し、budget_tokens は見ません。ツールが送るトークン予算はこの 3 つのどれかに合わせられます。
  • キャッシュ。キーが複数あるとき、jianmu は会話の最後のターンから 1 時間は同じ DeepSeek キーに留めます。次のターンは DeepSeek のキャッシュから読まれ、キャッシュなしで別のキーに送り直されることはありません。
  • 画像。ツールが DeepSeek の API に送る画像は、jianmu が一度だけアップロードし、以降のターンではファイル ID で指します。jianmu provider set deepseek image-files=off にすると毎ターンインラインで送ります。

残高と使用量

DeepSeek の行には DeepSeek から読んだ残高（合計、付与分、チャージ分）が表示されます。使用量 タブでは、jianmu を通ったトークン、キャッシュヒット、費用をツールとモデルごとに数えます。

よくある質問

DeepSeek を Claude Code で使うには？

jianmu に DeepSeek の API キーを追加し（プロバイダ → プロバイダを追加 → DeepSeek）、Claude Code の行で deepseek-v4-pro などの DeepSeek モデルを選ぶか、jianmu claude deepseek/deepseek-v4-pro を実行します。jianmu が Claude Code の settings.json を書き、リクエストを DeepSeek の Anthropic エンドポイント https://api.deepseek.com/anthropic に渡します。

Codex で DeepSeek は使えますか？

使えます。DeepSeek は Codex が話す OpenAI Responses API を自分で提供しているので、jianmu は Codex のリクエストをそのまま渡します。Codex の行でモデルを選ぶか jianmu codex deepseek/deepseek-v4-pro を実行すると、Codex の /model に並びます。

ANTHROPIC_BASE_URL を自分で DeepSeek に向ける必要は？

ありません。jianmu が Claude Code をローカルゲートウェイ 127.0.0.1:3425 に向け、DeepSeek のキーは jianmu が持ちます。Claude Code 自身のモデルを選び直せば元の設定に戻ります。

1 つの会話で Claude と DeepSeek を切り替えられますか？

できます。DeepSeek の Anthropic エンドポイントはツールを呼ぶターンに思考ブロックを求めますが、Claude で始めた会話にはそれが読める形でありません。jianmu が補うので、ルーティンググループは会話の途中で Claude から DeepSeek にフォールバックできます。

DeepSeek の推論レベルは？

low・high・max の 3 段階で、output_config.effort で指定し、budget_tokens は見ません。ツールが求めるレベルやトークン予算は、jianmu がこの 3 つのどれかに合わせます。

DeepSeek のキーを複数使えますか？

使えます。すべて DeepSeek プロバイダに追加してチェックを入れてください。jianmu はリクエストをキーに振り分け、キャッシュを生かすために 1 つの会話は同じキーに留め、残高が尽きたキーは次へ回します。

ツールごとのガイド：Claude Code で他のモデル、Codex で他のモデル、Gemini CLI で他のモデル、OpenCode で他のモデル。困ったときは GitHub Issues で質問してください。
