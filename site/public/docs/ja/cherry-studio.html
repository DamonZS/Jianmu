jianmu で Cherry Studio にすべてのモデルを

Cherry Studio は OpenAI 互換のプロバイダを使えるデスクトップのチャットクライアントです。jianmu は jianmu という名前のプロバイダとして自分を追加するので、jianmu にあるすべてのモデルが Cherry Studio に出ます。API キーを入れたプロバイダも、サインインした Claude・ChatGPT・Copilot のサブスクリプションもです。

jianmu はコンピュータ上の http://127.0.0.1:3425 でゲートウェイを動かします。OpenAI Chat Completions API を話し、各リクエストをモデルの背後のプロバイダ（Anthropic、Google、サブスクリプション）向けに変換します。ストリーミング、ツール呼び出し、推論もそのままです。Cherry Studio からは http://127.0.0.1:3425/v1 にある OpenAI 互換のプロバイダが一つ見えます。

Cherry Studio はプロバイダを自分のデータベースに保存し、jianmu はそこに書き込みません。代わりに Cherry Studio のプロバイダ追加リンクで自分を追加し、Cherry Studio で確認してもらいます。Cherry Studio 1.x と 2.x のどちらでも動きます。

Cherry Studio に jianmu を追加する

  1. jianmu にプロバイダを追加プロバイダ タブで API キー（DeepSeek、Kimi、GLM、Qwen、OpenRouter…）を追加するか、サブスクリプションにサインインします。
  2. エージェントタブを開くCherry Studio をこのコンピュータで一度起動すると jianmu に表示されます。データフォルダを移動していても見つけます。
  3. 「jianmu を追加」を押すCherry Studio の行の jianmu を追加 を押すと、Cherry Studio がモデルプロバイダの設定を開き、jianmu が入力済みになります：名前 jianmu、種類 OpenAI、ゲートウェイのアドレスとキー。
  4. Cherry Studio で確認する確認するまでは何も追加されません。

何も開かないときは、このコンピュータに Cherry Studio のリンクを開くアプリがまだありません。Cherry Studio を一度起動するか入れ直してから、もう一度 jianmu を追加 を押してください。

モデルを選ぶ

Cherry Studio はプロバイダのモデル一覧を /v1/models から取得するので、jianmu プロバイダには jianmu のすべてのモデルが プロバイダ/モデル の名前（例：deepseek/deepseek-v4-pro）で並びます。使いたいモデルを Cherry Studio の jianmu プロバイダに追加し、チャットでほかのモデルと同じように選びます。

あとで jianmu に追加したプロバイダは、Cherry Studio が次に一覧を取得したときに出ます。Cherry Studio 側の変更は要りません。一つのモデルの裏の複数アカウント、429 後の休止、フェイルオーバーは、ほかのエージェントと同じように働きます。

ターミナルから

ターミナル
jianmu cherrystudio add      # Cherry Studio を開いて jianmu を追加、そこで確認

cherry-studio という名前でも動きます。

追加されたかどうか

Cherry Studio にゲートウェイのアドレスのプロバイダができると、行にはボタンの代わりに jianmu と出ます。jianmu は Cherry Studio 2.x のデータベースを読み取り専用で読んで判断します。Cherry Studio 1.x はプロバイダを jianmu が読まない場所に保存するため、ボタンは残ります。

使用量とキー

ゲートウェイを共有していなければ、リンクのキーは Cherry Studio 専用なので、そのリクエストは jianmu の使用量で Cherry Studio の分として、コーディングエージェントとは別に数えられます。ネットワークでゲートウェイを共有してゲートウェイキーを使っている場合は、そこで使えるキーがリンクに入ります。

よくある質問

Cherry Studio で Claude や ChatGPT を使うのに API キーは要りますか？

要りません。jianmu で Claude・ChatGPT・Copilot のサブスクリプションにサインインすると、そのモデルが Cherry Studio の jianmu プロバイダに出ます。

jianmu は Cherry Studio の設定を変えますか？

変えません。jianmu は Cherry Studio 自身のプロバイダ追加ダイアログを開き、あなたが確認します。追加済みかどうかを表示するために、Cherry Studio のデータベースを読むだけです。

jianmu プロバイダのアドレスと種類は？

種類は OpenAI、アドレスは http://127.0.0.1:3425/v1 か、jianmu で設定したゲートウェイのアドレスです。

新しいモデルが Cherry Studio に出ないのはなぜですか？

Cherry Studio はプロバイダに追加したモデルだけを表示します。jianmu プロバイダのモデル一覧を取得し直して、新しいモデルを追加してください。

jianmu のエージェントタブに Cherry Studio がありません。

Cherry Studio をこのコンピュータで一度起動すると表示されます。Cherry Studio を一度開いてから、もう一度見てください。

コーディングエージェントも使う場合は どのエージェントでもサブスクを使うとはじめにを参照してください。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
