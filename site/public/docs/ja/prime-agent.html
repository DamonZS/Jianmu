Prime Agent

ドキュメント · ガイド

Prime Agent を任意のモデルで

Prime Agent は Prime Intellect が公開している Rust 製のコーディングエージェントで、コマンドは prime-agent です。自分のフォルダーに Pi と同じ settings.json と models.json を持ち、Pi と同じフィールドと型で読みます。jianmu は Pi と同じように設定するので、Prime Agent が DeepSeek、GLM、Kimi、Qwen、Claude、ChatGPT サブスクリプションなど jianmu の任意のモデルで動きます。

Prime Agent の設定

  1. jianmu にプロバイダーを追加プロバイダー ページで API キーを追加するか、サブスクリプションにサインインします。
  2. エージェント ページで Prime Agent のモデルを選ぶvia jianmu のモデルを選びます。
  3. prime-agent を実行新しいセッションはそのモデルで始まり、jianmu のモデルがすべて一覧に並びます。
ターミナル
jianmu prime-agent deepseek/deepseek-v4-pro

書き込まれる内容

ターミナル
~/.prime/agent/            （または $PRIME_AGENT_CODING_AGENT_DIR）
  settings.json            defaultProvider: "jianmu"
                           defaultModel:    "deepseek/deepseek-v4-pro"
                           defaultThinkingLevel
  models.json              providers.jianmu: ゲートウェイの /v1、
                           キー jianmu-prime-agent、jianmu のモデル

jianmu は models.json に jianmu というプロバイダーを加え、ゲートウェイの /v1 と jianmu のモデルを書きます。settings.json には defaultProvider、defaultModel、defaultThinkingLevel を設定します。あなた自身のプロバイダーと設定はそのままです。

Prime Agent のリクエストには User-Agent がないので、jianmu が渡すキーは jianmu-prime-agent という名前で、ゲートウェイはこれで Prime Agent の使用量として数えます。

PRIME_AGENT_CODING_AGENT_DIR

Prime Agent のフォルダーは ~/.prime/agent で、PRIME_AGENT_CODING_AGENT_DIR が設定されていればそちらです（~ はホーム）。相対パスは Prime Agent の作業フォルダー次第で jianmu には分からないため採用せず、~/.prime/agent に書きます。WSL の Prime Agent も設定できます。

あなたに任される設定

Pi と同じく、書くのはグローバルの settings.json だけです。次のものはあなたのもので、jianmu は変えません：

  1. プロジェクトの .prime/agent/settings.jsonそのプロジェクトの設定です。
  2. allowedModelsデーモンの許可リストで、外れたモデルははっきりエラーになります。
  3. subagentDefaultModelサブエージェントが始まるモデルです。

allowedModels を使っているなら、jianmu のモデルを加えてください。

元に戻す

Prime Agent の行で自分のモデルを選ぶか、下のコマンドを実行します。jianmu は最初に書く前に二つのファイルを控えています。その後変更がなければバイト単位で元に戻し、変更があれば jianmu のプロバイダーだけを消します。

ターミナル
jianmu prime-agent default

よくある質問

Prime Agent で DeepSeek や GLM を使えますか？

使えます。jianmu のエージェントページで Prime Agent に via jianmu のモデルを選ぶと、models.json に jianmu のプロバイダーが加わり、DeepSeek、GLM、Kimi、Qwen、Claude が使えます。

jianmu はどのフォルダーに書きますか？

~/.prime/agent、または設定されていれば PRIME_AGENT_CODING_AGENT_DIR（~ は展開）。相対パスは採用しません。

jianmu のモデルが許可されていないとエラーになります。

allowedModels にそのモデルがありません。jianmu はこのリストを変えないので、モデルを加えてください。

jianmu はどうやって Prime Agent のリクエストを見分けますか？

jianmu が渡す専用キー jianmu-prime-agent で見分けます。リクエストに User-Agent がないためです。

同じモデルを他のエージェントでも：Pi を任意のモデルで、Kimi Code を任意のモデルで、DS Bot を任意のモデルで、Muse Code を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
