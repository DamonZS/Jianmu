Cline を任意のモデルで

Cline は設定にあるプロバイダとモデルで動きます。jianmu は Cline 内蔵の OpenAI 互換プロバイダを jianmu のゲートウェイに向けるので、Cline の CLI、VS Code 拡張、デスクトップアプリが jianmu にあるどのモデルでも動きます：DeepSeek、Kimi、GLM、Qwen、OpenAI キー、ChatGPT や Copilot のサブスクリプション。Cline にキーを貼る必要はありません。

Cline はプロバイダを ~/.cline/data/settings/providers.json（または $CLINE_DIR の下）に置きます。jianmu は Cline 自身の openai-compatible プロバイダをゲートウェイのアドレスと Cline 専用のキーに設定し、使用中のプロバイダにして、models.json に jianmu のモデルを並べます。このプロバイダが自分で出す一つのモデルの代わりです。元の内容と使っていたプロバイダは控えておき、元に戻すときに戻します。ゲートウェイは各リクエストをそのモデルのプロバイダ向けに変換し、ツール呼び出しと推論もそのままです。

Cline をつなぐ

  1. jianmu にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクリプションにサインインします。
  2. Cline の行でモデルを選ぶエージェント タブの Cline の行でモデルを選びます。
  3. 新しい Cline セッションを始めるCline はセッション開始時にプロバイダを読みます。開いているセッションは元のモデルのままで、新しいセッションがこれを使います。
ターミナル
jianmu cline deepseek/deepseek-v4-pro    # Cline を DeepSeek で
jianmu cline                             # 今のモデルを見る

モデルと推論の強さ

行では Cline が求める推論の強さも設定できます：none、low、medium、high、xhigh。none は Cline 自身の選択と同じく思考をオフにします。

ターミナル
jianmu cline effort high
jianmu cline effort default    # Cline の既定に戻す

VS Code 拡張

Cline の VS Code 拡張は同じフォルダを使いますが、プロバイダ、モデル、アドレス、キーを自分の状態から先に読みます：Act と Plan モードのプロバイダとモデル、そして OpenAI 互換のキーです。jianmu はこれらも設定し、元の値を控えます。拡張は起動時に一度だけ読むので、変更後は VS Code で Developer: Reload Window を実行してください。

デスクトップアプリ

Cline のデスクトップアプリは、入力欄で選んだモデルと推論の強さを自分で持ち、これらのファイルからは読みません。選択には jianmu の下に jianmu のモデルが出るので、そこで選んでください。jianmu の行が設定するのは CLI と VS Code 拡張です。

元に戻す

Cline の行で jianmu を外すか、jianmu cline default を実行します。jianmu は使っていたプロバイダ、モデル一覧、拡張の設定を元どおりに戻します。

よくある質問

Cline で ChatGPT サブスクを使えますか？

使えます。jianmu で ChatGPT にサインインし、Cline の行で GPT モデルを選びます。Cline のリクエストは jianmu に届き、jianmu がサブスクを使います。

モデルを変えたのに Cline が古いモデルのままです。

セッションは開始時のモデルを使い続けます。新しいセッションを始めてください。VS Code 拡張ではウィンドウを再読み込みします。

jianmu が Cline に自分のプロバイダを加えないのはなぜですか？

Cline はセッション開始時に知らないプロバイダを拒むため、jianmu は Cline 内蔵の OpenAI 互換プロバイダを使います。

Cline のデスクトップアプリでも使えますか？

使えます。選択の jianmu の下に jianmu のモデルが出ます。アプリは Cline のファイルから読まないので、そこで選んでください。

同じモデルを他のエージェントでも：OpenCode で他のモデル、Claude Code で他のモデル、Hermes Agent を任意のモデルで、Goose を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または Discord で質問してください。
