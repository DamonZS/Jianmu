Copilot CLI

仕組み Copilot CLI を接続 推論の強さ 自分の providers.json 元に戻す よくある質問

ドキュメント · ガイド

Copilot CLI を任意のモデルで

GitHub Copilot CLI は自分のモデルプロバイダ（BYOK）で動かせ、その場合 GitHub へのサインインは要りません。jianmu は自身をその一つとして Copilot CLI に加えるので、copilot で jianmu にある任意のモデルを使えます：DeepSeek、Kimi、GLM、Qwen、OpenAI キー、ChatGPT サブスク。Copilot にキーを貼る必要はありません。

Copilot CLI のフォルダは ~/.copilot（または $COPILOT_HOME）で、独自のプロバイダはその中の providers.json（または $COPILOT_PROVIDERS_CONFIG）にあります。jianmu はこのファイルに jianmu という OpenAI 互換のプロバイダを加えてゲートウェイのアドレスと Copilot 用のキーを書き、その横に jianmu のモデルを、名前・コンテキスト長・出力上限付きで加えます。そして settings.json の model を jianmu/<モデル> にします。ゲートウェイは各リクエストをモデルのプロバイダ向けに変換し、ツール呼び出しも推論も保ちます。

Copilot CLI を接続

  1. jianmu にプロバイダを追加プロバイダ タブで API キーを追加するか、サブスクにサインインします。
  2. Copilot CLI の行でモデルを選ぶAgent タブで jianmu の下のモデルを選びます。
  3. copilot を起動そのモデルで動きます。Copilot 自身の /model にも jianmu のモデルが並びます。
ターミナル
jianmu copilot deepseek/deepseek-v4-pro    # settings.json では jianmu/deepseek/deepseek-v4-pro
jianmu copilot                             # Copilot CLI の今のモデル

行には Copilot 自身のモデルと、Copilot に任せる auto も並ぶので、GitHub のモデルに戻したいときはそれを選びます。

推論の強さ

行では Copilot がモデルの横に保存する effortLevel を設定できます。段階はモデル自身のもので、Copilot の一覧に書かれていなければ low、medium、high、xhigh です。Copilot 自身の /model でモデルを変えると消えます。

ターミナル
jianmu copilot effort high
jianmu copilot effort default

自分の providers.json

jianmu が扱うのは jianmu という名前のプロバイダと、それを指すモデルだけです。他のプロバイダ、そのモデル、ファイルの他のキーはそのまま残り、jianmu のプロバイダに自分で加えたキーも残ります。正しい JSON でない providers.json はそのまま置かれ、上書きされません。jianmu のモデルが変わると jianmu は自分の項目を更新し、内容が変わるときだけファイルを書きます。

元に戻す

行で Copilot 自身のモデルを選ぶか、jianmu copilot default を実行します。settings.json から model を消し、providers.json から jianmu のプロバイダとモデルを取り除き、残りはそのままにします。

よくある質問

GitHub Copilot のサブスクは必要ですか？

不要です。Copilot CLI の独自プロバイダは GitHub へのサインインが要らないので、Copilot のプランがなくても jianmu のモデルを使えます。

Copilot CLI で ChatGPT サブスクを使えますか？

使えます。jianmu で ChatGPT にサインインし、Copilot CLI の行で jianmu の下の GPT モデルを選びます。Copilot のリクエストは jianmu に届き、jianmu がサブスクを使います。

settings.json が jianmu/deepseek/… なのはなぜですか？

Copilot はプロバイダのモデルを「プロバイダ/モデル」と書き、jianmu のプロバイダの名前が jianmu だからです。コマンドラインでは jianmu/ を省けます。

自分の BYOK プロバイダは残せますか？

残せます。jianmu が変えるのは providers.json の自分のプロバイダとモデルだけで、自分のものはそのままです。

同じモデルを他のエージェントでも：OpenCode で他のモデル、Claude Code で他のモデル、Raycast を任意のモデルで、Qwen Code を任意のモデルで。エラーが出るときは よくあるエラーの直し方、または GitHub Issues で質問してください。
